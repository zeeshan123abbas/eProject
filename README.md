A web application built as an **Aptech eProject** with **ASP.NET Core MVC**, showing how a semester project is structured from controllers to Razor views.

## 🧱 Structure

```
eProject/
├── Controllers/   Request handling
├── Models/        View models
├── Views/         Razor pages and layout
├── wwwroot/       CSS, JS and assets
└── Program.cs     App startup and routing
```

## ▶️ Getting started

```bash
git clone https://github.com/zeeshan123abbas/eProject.git
cd eProject/eProject
dotnet run
```

Or open `eProject.sln` in Visual Studio and press F5.

## 🎓 About Aptech eProjects

Every Aptech semester ends with an eProject: a real application built by students against a client brief. This repo is a reference for structuring one cleanly.
